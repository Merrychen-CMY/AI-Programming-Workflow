# 3.1.2 配置诊断修订验证范围

日期：2026-11-18。用户在点击测试API后收到无法区分原因的统一错误；本次修复该诊断缺陷，保持配置→环境→需求→开工确认→自动推进→最终审核顺序。

## 实施与证据

- 将配置读写、宿主凭据服务、HTTP状态、网络错误和模型响应问题分别分类；仅显示固定白名单消息、错误编号、测试阶段和数字HTTP状态。上游消息、异常文本、密钥及模型内容均不作为公开诊断。
- 响应读取限制500,000字节；旧PASS在探测前失效。保持每次最多两次请求、每次2048输出token和45秒超时，不自动重试、切换模型、提高预算或启动产品任务。
- 新增HTTP 401/403/404/429/400/503、非JSON拦截页、网络/DNS/证书/超时、输出上限、响应拒绝/畸形/过大、原始异常脱敏、凭据服务失败及旧PASS失效测试。测试使用模拟API和凭据，并通过真实本机HTTP配置服务校验诊断边界。
- 本机只读取非密钥配置字段；保存模型为gpt-6-astra，Python/Codex路径有效。使用不带Authorization的GET请求连接API模型端点，收到HTTP401，说明该测试进程可以到达接口。该401是本次无凭据请求的结果，不是用户先前测试失败的返回码。

本机静态校验通过；Node插件测试50项全部通过；Python完整回归356项中353通过、3项因本机条件跳过，跳过不记为通过。CI以对应提交运行日志为准。
