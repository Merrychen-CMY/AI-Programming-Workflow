## 实现范围

- 新任务以adaptive_limits启用两层边界，用户总上限与L1当前分配分开；原始开工确认和输入不改写，旧任务保持原行为。
- 实现、同因、设施、审核、修订、API与时间额度不足进入BUDGET_REVIEW_PENDING。L1记录剩余工作、证据、预期收益和策略，调整通过才可继续，不清零累计消耗。
- 增加具体授权申请与原生用户批准/拒绝，绑定准确申请和任务状态。目标/AC/范围变化使旧批准失效，重新规划及独立审核；纯资源调整保持产品基线。
- 暂停时保存待分析问题、待修复与设施重试；恢复先经L2诊断。预算暂停不标成真实UNKNOWN，不跳过根因分析或重复已完成任务。计划预算快照与当前分配分离；初始化前额度不足先暂停，不留下未绑定委托的半初始化任务。
- 最终报告含授权版本、调整前后值、理由、消耗及DOT API已报告用量；缺失用量标为未知。原华为145父项/50子项、Doxygen12项/33子项、PC-U01～26与独立验证要求保留。

## 明确限制

没有调用真实付费API、安装本机插件或执行用户产品、刷写及HIL；48项产品验收场景仍NOT_RUN。历史记录没有迁移或清除。

本版无跨L1/DOT/Codex的统一货币或总token硬上限；暂停等待仍计入总经过时长。追加授权接口只支持limits、expires_at、allowed_paths、hard_constraints、authorized_context。设备/网络/外部交付执行器、取消独立验证的开关、通用UNKNOWN恢复及最终报告撤销不在此接口内；原生用户批准不能替代事实核实或真实验证。本机记录不是签名审批服务或同账户安全隔离。
