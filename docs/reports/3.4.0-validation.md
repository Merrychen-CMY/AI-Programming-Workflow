# ReqPilot 3.4.0 自动更新验证

日期：2026-11-19。本版增加稳定入口和兼容工作流更新；已确认任务固定原运行版本，不自动迁移授权或任务历史。

## 验证范围

覆盖模拟发布下载、同会话切换、固定版本跨重启恢复、离线保留、摘要校验、路径及重定向拒绝、工具/ABI不兼容、缓存损坏、并发安装和检查节流；通过真实本地Python管道核对缓存运行器状态入口。另覆盖更新后旧环境/待确认摘要不能批准。

本机Python完整回归420项，其中417项通过、3项因Windows符号链接/可执行位能力跳过。Node完整回归91项，其中90项通过、1项因Windows符号链接权限跳过；包含32项新增更新测试。静态校验310份清单文件通过。嵌入式C契约44 + 23 + 15 = 82项通过，未运行产品测试。GitHub正式发布作业依赖静态检查、完整测试、C契约及真实Doxygen示例全部通过。正式产品48场景仍为NOT_RUN。

## 边界

本机宿主接口依据DeepSeek Harness0.2.2-rc.3随包源码。没有向正在使用的Harness会话安装或注入插件，也没有执行真实GPT付费请求、产品编程、设备操作或HIL。模拟Host中的同会话切换及本地Python管道通过，不等同于真实Harness端到端验证。首次仍需安装带更新入口的版本；工具/主版本/ABI变化仍需宿主升级；已确认旧任务不会自动获得新运行器修复。

更新器保存准确版本缓存，不写任务记录，不清除UNKNOWN、不撤销最终报告。来源为固定公开GitHub仓库的HTTPS正式发布；内容哈希不替代独立发布签名或同账户隔离。缓存未实现自动清理，异常退出的安装锁需要先核实旧安装进程。损坏的已固定版本会阻止运行，不自动切换版本处理产品动作。
