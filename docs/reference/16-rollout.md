# 16 分阶段启用

> v2.0使用范围：本章保留原完整技术参考。默认用户流程为L1整理需求、用户批准、DOT执行；本章内部角色和正式工具契约按 [进阶范围](../advanced-profile.md) 适用，不要求用户逐层操作。

第一阶段完成单任务闭环，人工传递也可以，但每一步必须保留版本和证据。未接通的接口明确显示 BLOCKED，不用临时手写 PASS 填补。

第二阶段接通 Dot 的 L2 调度、统一问题队列、受控 wrapper、证据存储和服务端门禁。以第15节及21.2所有适用拒绝测试通过为上线标准，不以工具安装成功为标准。

第三阶段再增加并发任务。保持每个任务独立工作区、明确依赖和唯一写入者；所有子任务集成后重新形成项目候选并执行整体验收。任务级成功不能代替集成验证。

持续记录任务完成率、首次验收通过率、需求返工率、硬件环境失败率、每次交付成本和人工决策次数。先改善失败原因，再提高并发。
