# 1 统一回流架构

> 3.0适用范围：L1是唯一用户入口，在原始委托内代理批准需求、计划和变更，用户只审核L1最终报告。原技术契约保留，正式保护仍适用。见 [当前规则](../../AGENTS.md)；历史人工Ready/签名服务示例不自动授予L1身份或权限。

架构图的可检索 Mermaid 版本见 [架构与基线](../architecture.md)。

图 1  双 L1 基线与 L2 统一回流调度

流程控制器贯穿各层，保存状态、唯一标识、版本绑定、审批、权限、预算与证据引用。L2 负责根因分析和调度决策，控制器负责校验并执行；控制器本身不替代L1的代理决策、内部L1-V或最终人工报告审核。Dot 可以承载 L2 的项目管理角色。L5 可以使用同一工作台汇报，但其验收汇总职责与 L2 调度职责必须分别记录。

正向流程为 Product L1 → 门1 → L2 拆解与协调 → L3 实现 → 门2 冻结候选 → L1-V 候选验证任务包 → V0 → L4 独立验证 → 门3 → L5 验收汇总和交付申请 → 门4 → delivery_guard。L1-V 的通用验收计划在开工前建立，候选冻结后再实例化。L4/L5 可立即停止不安全操作和保存证据，但所有恢复、修复或重试调度均须经过 L2；聊天回复不能替代控制器记录。
