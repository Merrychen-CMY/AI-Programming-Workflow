修复会员登录成功后，模型目录响应超过共用500,000字节限制而被截断、导致无法选模型的问题。

- 成功模型目录响应使用独立8 MiB上限，按实际流字节累计，超限立即取消读取并返回明确诊断。OAuth及错误响应仍保留原限制。
- 页面仅收到可展示模型的ID和名称，保留服务端顺序，不传递大段目录元数据。
- 空目录或没有可展示模型时明确返回CHATGPT_MODELS_EMPTY，不再误提示“账户已刷新”却没有选项。
- 保留登录凭据，不增加模型请求，不切换付费API；职责、权限及产品任务限制不变。兼容ABI12，支持3.23.2来源按既有流程迁移。

验证包含超过旧限制的中文流式目录、本机配置页接口、8 MiB边界与溢出取消、空目录、凭据保留和OAuth原上限。使用模拟服务与凭据，不读取用户Token，不发送模型请求。实际账户目录仍需用户更新后刷新验证。
