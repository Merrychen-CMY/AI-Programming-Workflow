# ReqPilot 3.7.0

API异常先进入L1评估，支持在授权上限内调整等待时间。新增超时、连接、DNS/TLS、HTTP拒绝和响应错误分类，保留实际耗时、原请求、累计次数和未知用量。

已明确未发送或拒绝的请求可经L1评估继续；原结果不明时必须由用户在原生界面明确允许下一次请求，提示可能重复计费。调参不清除UNKNOWN、不自动重放、不撤销最终报告，产品工作会话中断保护保留。

新增工具需要安装ABI5插件入口。正常3.6.1任务可按既有原生批准流程迁移；旧未决请求、宿主中断和已结案任务不会因此恢复。固定六字段进度汇报继续有效。

使用见[API评估指南](../guides/api-recovery.md)，检查范围见[验证记录](../reports/3.7.0-validation.md)。
