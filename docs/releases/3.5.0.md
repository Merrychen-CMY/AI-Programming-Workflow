# ReqPilot 3.5.0

已开工任务可以在原对话升级：核对任务和版本后，由Harness原生界面确认准确迁移，保留原授权、累计消耗、完成任务、失败记录和证据。旧审批/候选失效，L1重新组织独立审核，DOT完成剩余工作并完整重新验证。升级本身不调用付费API或Codex。

支持源版本3.4.0、3.4.1的原生任务，要求原运行缓存完整、任务暂停且无未知操作或最终报告。运行中、UNKNOWN、终态和未记录修改不能借升级解锁；3.3.x及更早任务仍需单独评估。

首次安装reqpilot-3.5.0.tgz并让Harness加载ABI3入口。旧入口不能自我替换，可能需要按宿主要求重新加载原对话；不会要求新建任务或重填需求。此后兼容工作流可在原对话经确认迁移。原会话入口是否已更新以实际工具行为为准，未声称已在你的真实Harness安装。

新增预览、原生批准、迁移日志、崩溃后精确本地写入恢复和拒绝测试。详见docs/guides/task-upgrades.md与docs/reports/3.5.0-validation.md。产品/HIL验收仍未运行。
