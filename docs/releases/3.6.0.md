# ReqPilot 3.6.0

修复Windows深层构建产物复制到控制目录后超过传统路径长度限制而触发Errno 2的问题，快照和归档改用扩展长度文件路径，无需修改系统注册表。保留构建产物及完整性校验。

修复规划完成后首次初始化中断、部分快照导致无法继续的问题。新增独立的初始化恢复预览和原生审核入口，保留原确认、API消耗及部分文件；基线变化必须明确批准采用新起点，并重新规划及独立审核。初始化失败保存本地错误，不再把已知复制失败一律当作结果未知。

此功能只支持3.5.0/3.6.0的未提交初始化，不处理产品执行UNKNOWN、未完成API请求、已初始化任务或最终报告。恢复不调用付费API、不写产品、不派工、不重置预算或截止时间。

本版入口为ABI4，需要先在Harness更新插件安装包；旧ABI3不能仅靠运行器自动更新获得新入口。旧对话是否已加载新入口必须核实。正常任务仍可按已有原生确认升级；初始化阻塞任务使用独立恢复流程。

使用方式见[初始化恢复指南](../guides/initialization-recovery.md)，测试范围见[验证记录](../reports/3.6.0-validation.md)。
