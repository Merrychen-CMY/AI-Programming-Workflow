# ReqPilot 3.19.0

修复 L1/L2 对材料超限和计划草案错误的协作恢复，减少把可处理问题反复退给 L1 的情况。

- 历史调查、额度变更和工具输出使用有界视图，原件完整保留；DOT 直接分页读取摘要绑定的证据，无需 L1 复制日志。
- 已完成的纯计划格式/校验错误由 L2 自动纠正一次，失败和实际 API 消耗留存；资源不足由 L1 评估，结果未知的请求不自动重发。
- 残余材料超限返回分项大小及 L1 具体恢复步骤。L1 主动整理、协调 L2 调查；精简已批准需求仍须逐项核对和独立重审，不要求用户代为整理。
- 最终 Markdown 显示结论、未完成项、问题、额度与调整摘要，完整原始 JSON 单独保留并提供索引。

保持 ABI12 和原有职责、权限与独立验证要求。已经确认的任务仍固定原版本；升级须走原生任务升级流程，不自动清除未决操作或重开最终报告。

详见[调查与材料处理](../guides/investigation.md)和[计划纠正](../guides/plan-rejections.md)。运行器回归和真实历史材料的只读重放，不等于真实 Harness 产品任务或 LED/HIL 验收通过。
