# ReqPilot 3.12.0

审核报告成为可打开的Markdown文件，执行任务按最小范围推进，长时间没有工作进展时原会话问询。

- 需求审核、计划审核和最终成功/失败报告均生成Markdown；文件绑定内容摘要，原JSON、失败证据和累计消耗保留。
- Harness将报告登记到同一聊天的文件卡；L1先发送结论和报告链接，再请求最终人工审核。卡片在本轮结束后显示。
- 固化六项执行约束：最小改动、先定范围、只读不改不测、不扩展机制、完成即停、无进展时问询。非验收问题只列为建议，不顺手修复。
- 独立Codex会话改用App Server；连续120秒无可见工作进展时问“你正在做什么？”，明确当前步骤、阻碍和最小下一步。运行中的命令不误判，原超时和额度不延长。

需要安装ABI8主包，并使用支持App Server的Codex。已开工任务保持原版，按原生预检与确认升级。没有调用真实模型或操作产品来证明本版；验证范围见仓库测试与[执行范围指南](../guides/execution-scope.md)。华为C、Doxygen、独立验证和授权边界继续有效。
