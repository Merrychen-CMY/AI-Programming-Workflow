# ReqPilot 3.9.1

问题尚未查明原因时继续由 L2 调查，缺资料、权限或资源交给 L1 协调，不再自动生成最终 UNKNOWN。材料超限是明确未发送的本地拒绝，保留原始记录，由 L1 评估和整理后继续。

- API 回流使用带原件路径、SHA-256 和省略说明的证据摘要；完整原件可分页读取。
- 移除根因分类 unknown，待诊断问题记录为 L2 调查待办，不伪造根因，也不删除历史。
- L1 可在授权内处理，越界时通过现有原生确认申请权限或资源，不因需要授权提前结案。
- 未决产品操作允许分析已有证据，仍保留原操作保护，禁止盲目重放。
- 兼容 ABI6，支持正常 3.8.0 任务经原生确认迁移。旧中断和已生成的最终报告不自动重开。

本次实际失败材料在隔离环境中从约323 KB整理为约98 KB的API输入，模拟L2响应后进入待决策状态，没有生成最终报告。回归、真实JS/Python管道、本地测试及版本迁移均有验证；模型与原生确认使用测试夹具，不代表真实Harness或ESP32产品验收。详见[验证范围](../reports/3.9.0-validation.md)。
