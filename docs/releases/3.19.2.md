# 3.19.2 — 各层主动排障

- 各层先查证并处理本次职责、授权内的阻塞；未解决时交接已尝试动作、实际证据、最小方案和剩余决策，禁止只转报错。
- 接入L1原生提示、GPT/DOT开发者提示及所有Codex执行/测试/审核/调查会话；明确测试设施处理与只读审核的不同边界，L5主动核对汇总和交付材料。
- 同步六层角色、交接/需求/计划/报告模板及结构化策略；修正角色文档中资源增加仍需用户批准的旧表述。
- 沿用现有草案纠正、L2分诊派修、设施恢复、L1评估及原生核实入口；不增加通用自动重试器，不更改权限、状态门禁、累计消耗或独立证据要求。
- ABI保持12。已开工任务需按既有原生升级流程采用新版；已结案任务不自动恢复。

验证结果随本次发布记录；提示与控制器测试不能证明模型必定自愈所有故障，也不代表真实产品/HIL验收通过。
