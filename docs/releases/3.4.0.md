# ReqPilot 3.4.0

增加自动检查正式发布、下载校验及兼容工作流切换。首次安装本版后，后续兼容更新无需每次手动安装和重开对话。

未开工会话在下一次工具调用采用新版；旧环境和待确认摘要需要重新检查。已确认任务固定原运行版本，继续原会话，保留全部授权、预算、失败和证据。更新器不清除UNKNOWN，不迁移历史任务，不撤销最终报告。

默认在工作流工具活动时最多每6小时检查一次；可让L1检查更新或关闭/开启自动更新。固定访问本仓库正式发布，不发送项目资料和凭据，不调用GPT API。下载/完整性/导入失败保留原可用版本。

安装资产为reqpilot-3.4.0.tgz；reqpilot-runtime.json.gz和reqpilot-update.json供内置更新器读取。主版本、工具接口或入口ABI变化仍需升级宿主安装包。旧版已开工任务没有完整运行缓存时，不能直接覆盖安装并假定其自动恢复。

使用和验证边界见仓库docs/guides/automatic-updates.md与docs/reports/3.4.0-validation.md。未声称真实Harness会话或产品/HIL验收已通过。
