# 3.20.2 — 函数内部注释右侧对齐

- PC-U15 revision 3明确同一函数内的流程注释放在对应代码右侧，用空格对齐成一列，嵌套分支保持同列。
- 取消“逻辑段总述”作为普遍上方例外；长文字先精简，确有华为或可读性冲突才记录具体依据处理。
- 同步派工/审核提示、规范正文、LED片段与Doxygen教学实现；代码可执行内容不变。
- 华为优先，流程、职责、权限和ABI12不变；已开工任务通过原升级入口采用，不自动改动旧任务。

见[排布规则与示例](../../standards/embedded-c/v1.3/project-constraints/readable-style.md)。排版和文档工具验证不能替代真实产品的注释语义审查。
