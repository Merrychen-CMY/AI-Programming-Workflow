# ReqPilot 3.8.0

修复正常开工中审查材料不完整、长返回遮蔽最新问题、审批顺序错误造成中断锁三个问题。

- 控制器自动提供原始环境/基线、真实累计用量、API恢复记录和固定版本规范；审查材料不靠L1反复转述。
- 工具优先返回最新审查问题和下一步。新增dot_read_record分页读取完整记录，保留全部原文。
- 未开始执行的审批顺序拒绝正常返回，不造成新的UNKNOWN。未批准的dot_run同样不发起API请求。
- 最终报告确认显示摘要与完整报告路径，继续绑定完整报告哈希。

安装reqpilot-3.8.0.tgz；新增只读工具需要ABI6宿主加载。已确认任务仍固定原运行版本，旧中断及失败报告不会自动恢复，不修改用户授权和历史消耗。

验证包括真实JS/Python管道和实际本地测试命令；模型回答与原生确认仍有模拟，尚不构成真实Harness桌面/ESP32/HIL验收。详细范围见docs/reports/3.8.0-validation.md。
