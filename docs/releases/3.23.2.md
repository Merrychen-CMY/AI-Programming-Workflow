# ReqPilot 3.23.2

修复会员登录将所有HTTP失败都归为“授权或续期失败，请重新登录”的问题。

- 区分浏览器回调后的凭据兑换、登录配置、公钥获取、凭据续期和模型目录阶段。
- 保留HTTP状态、响应类型、白名单OAuth错误码和已知格式请求编号；不输出响应正文、任意错误消息、授权码或Token。
- 分别提示HTML拒绝、浏览器挑战、授权码失效、客户端配置、账户资格、权限、地区、限流和服务故障。
- 身份配置/公钥HTTP失败保留真实阶段，不再误报签名失败。临时拒绝保留凭据；只有服务明确确认续期凭据失效才清除Token，保留客户端注册。
- 不自动重放授权码、不自动切换付费API，不改变L1/DOT职责、任务权限和计费选择。兼容ABI12，支持3.23.1来源按既有原生确认流程迁移。

验证使用模拟OAuth服务、真实JWT签名和本机HTTP回调，不使用用户授权码或真实凭据，不发送模型请求。测试通过不表示用户当前403已经解除；加载新版后由用户重新发起一次登录，再依据脱敏诊断定位外部拒绝原因。
