# ReqPilot 3.22.1


- 新增官方ChatGPT会员登录模式：浏览器授权、账户选择、账户模型清单、凭据续期、退出和两项连接测试。
- DOT沿用公开Responses接口，通过宿主处理流式响应和工具namespace；保持L1/DOT/独立执行验证分工。
- 会员模式不读取API Key，不自动切换付费API；额度/授权失败进入现有L1评估，未决请求不自动重放。
- 账本记录接入来源、返回用量及会员模式不支持单次输出token硬上限的事实；提示管理官方额外积分权限。
- 已有API配置和已确认任务保持原接入方式；本版不自动迁移旧任务认证。会员模式应在新任务开工前配置。

Bootstrap ABI12保持兼容。凭据使用现有Harness服务；新增JWT验证库随包固定分发。具体步骤见[会员登录指南](../guides/chatgpt-login.md)。

验证采用模拟OAuth/模型服务、真实JWT签名和本地Python管道。未登录用户真实账户、未调用付费或会员模型；真实账户资格和在线调用需要安装后由用户授权并点击测试。

修正Windows工作区与GitHub检出的换行差异，确保清单摘要、安装包与远端文件一致。3.22.0标签因该检查未通过，未发布正式资产；使用3.22.1。
