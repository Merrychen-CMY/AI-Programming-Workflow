# 首次跑通

1. 按[原生插件指南](l1-plugin.md)安装并新建“ReqPilot · 需求领航”会话；先在配置页填写模型和密钥，主动测试API。
2. L1调用workflow_check_environment检查基础环境，无需项目需求。必需条件失败/未知时先解决缺口，不继续收集需求。检查不调用GPT、不派工。
3. 基础环境通过后，用户沟通小任务的原始需求、参数、已有环境和限制；L1补齐九项信息，复核项目特有环境并固定项目指纹与有限预算，用户集中确认开工。
4. L1先在用户确认的总上限内调用l1_adjust_limits分配当前额度，再生成需求和内部L1-V验证要求，调用dot_plan取得GPT计划，dot_initialize固定起点；调用l1_approve分别审查批准需求和计划。核对独立审查记录与delegated_l1身份。
5. L1调用dot_run，检查独立开发、真实测试命令、独立测试与审核在同一候选上留下证据；嵌入式C增加真实Doxygen与华为逐条证据。
6. 试验至少一个实现失败：必须先经DOT根因分析，再派L3，产生新候选重验。再检查需求/测试计划问题会返回L1而不是弹出用户中间审批。
7. 成功或失败都由L1核查报告并调用l1_submit_report，然后交用户审核。缺证据不能成功；失败确认后停止。只验证本地流程时不执行发布或设备刷写。

开工时说明implementation_attempts的单位：整个任务的L3实现派工次数，初次与修复合计；3个初始任务会占满3次预算。DOT把读码/注释修改放入相应实现任务，构建、Doxygen生成、测试/HIL和审核安排在独立验证中，所有AC保留。不能省略工作或把3次解释为每任务3次；3只是旧固定示例，新任务由L1按规模分配，额度耗尽先评估。提高用户总上限须另获明确批准。

规划若返回PLAN_REJECTED，先读诊断和拒绝草案，修正后在原任务dot_plan；若尚未初始化，不用l1_revise。已有运行基线则在允许的暂停状态l1_revise，重新独立审查并批准。拒绝后不得派工、初始化无效草案或沿用旧批准；相同输入与相同反馈不盲重试。已发API及总时间继续累计，真正UNKNOWN不重放，旧版锁定任务不自动迁移。详见[恢复指南](plan-rejections.md)。

运行以下仓库自检可先核对接口/状态拒绝逻辑，但不能代替上述真实联调：

```powershell
python scripts/validate_repo.py
python -m unittest discover -s tests -v
```

拒绝重点：无委托、原始目标漂移、扩大范围/预算、同会话自审、缺/旧证据、API超限/失败重放、L1代审最终报告。真实结果另存产品证据，不把48项参考场景默认改为PASS。

新增回归重点：7个阶段误列tasks且预算3时正常拒绝、修正后继续且累计不重置、已用2次又提2个任务时拒绝、拒绝后初始化仍正常返回、旧批准阻断，以及真实传输/落盘异常仍保留UNKNOWN。

插件还须拒绝：配置未完成就检查基础环境、基础检查未通过就准备需求、重查失败/中断沿用旧PASS、未确认就调用DOT、取消/跳过确认、确认期间摘要/模型/项目变化、必需环境未知、模型伪造会话身份、重启后重放UNKNOWN、最终报告被改写。检查结果记录在真实任务中；模拟测试不能填入产品PASS。

动态资源首次验证还应覆盖：初始分配后才能调用DOT；当前实现额度不足进入BUDGET_REVIEW_PENDING；调整后先继续未完成的根因分析，再恢复诊断后的任务；超上限只能由原生用户批准；范围变化必须重审；已用次数和时间不清零；最终报告含全部调整理由和实际消耗。检查[资源管理指南](adaptive-resources.md)，不要通过删除记录测试恢复。

已开工任务需要升级时，使用[原对话任务升级](task-upgrades.md)：upgrade_preview预检→upgrade原生确认→重新独立审核→DOT继续与完整验证。不得改写原开工确认或清零历史。

初始化失败且没有state.json时，不反复调用dot_initialize；按[初始化恢复](initialization-recovery.md)先预览、原生批准，再继续。拒绝/跳过/确认期间变化不得清除标记；部分文件和已用额度保持。

非成功结案必须先有 L1 明确评估。L2 先考虑权限内方案，越界提交方案；自动异常只暂停。见[结案规则](../guides/l1-closure.md)。

新增拒绝测试：让DOT规划/执行建议停止，确认只暂停；以裸理由调用l1_stop，确认COMPLETED_REJECTED且没有最终报告；提交完整L1评估后才生成非成功报告；核对未决操作及累计消耗不被清除。
