# 接入一个项目

用户只需向L1说明原始目标、参数、环境、仓库位置和限制，并审核最终报告。L1负责整理需求、内部验证计划、有限委托与批准；DOT负责规划和独立执行。

1. 固定本仓库commit，L1先读AGENTS.md和L1.md，补齐关键事实。
2. L1维护需求、委托和本机设置；按 [Harness接入](l1-harness.md) 挂载专用工具桥，核对真实API、Codex、测试及设备能力。
3. 独立审核通过后L1批准需求/计划，调用DOT执行。范围内修订回L1，超界/缺关键事实汇总失败报告。
4. 按 [首次跑通](first-run.md) 从一个小任务验证，最后由L1提供完整报告和产物，用户只审核最终报告。

保留项目已有保护、构建/测试要求和明确授权。嵌入式C继续采用华为规范与Doxygen，用户不手填逐条适用性表；由DOT维护，独立验证核对。
