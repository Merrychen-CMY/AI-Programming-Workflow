# 附录 D 项目适配与资料索引

项目配置必须补齐的内容

采用 project-profile.template.json 或项目现有配置描述：项目身份、规范版本、工具链与依赖、硬件资源、模块映射、规则检查方法、允许动作、设备身份、日志配置、参数与标定、检查入口、执行预算和例外。不得把通用模板中的空值当作生产默认值。

模板生命周期为 DRAFT、READY、ACTIVE、CLOSED；报告为 DRAFT、FINAL。READY 表示可执行，CLOSED 不等于通过。规范版本为 1.2，字段结构未变，schema_version 仍为 1.1；项目模板默认采用规范 1.2，校验兼容 1.1。结构校验不替代语义与现场核对。

当前 ESP32 项目的阶段约束

本次工作只更新规范及配套资料，不修改 ESP32 业务代码、算法、标定或硬件。当前旧源码规范化阶段仅补全注释，禁止借格式、头文件或架构整改改变非注释实现；新增检查工具或后续功能开发按独立任务范围实施。

GPIO、SPI 速率、DMA 缓冲、HX711 增益、阈值及校准系数保存在项目配置中。本产品人工加料方式、测量与保持值语义、零点与漂移补偿前提应转为具体需求和用例，不能固化为其他项目的默认假设。

配套文件使用顺序

阅读使用说明，采用规范版本；将项目入口模板内容纳入项目 CONTRIBUTING.md，并在 AI 指令中引用。

复制并填写项目配置和任务模板；保留未确认项为 DRAFT，校验结构及执行条件。

补充测试计划、独立判据及证据路径；将项目实际检查命令接入统一入口。

执行后生成逐项结果和交付记录；更新变动清单、校验值及必要复核。
