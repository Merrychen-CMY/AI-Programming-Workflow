# L5 验收汇总与交付申请

仅在用户或已授权的项目调度明确分配该角色时执行；阅读本文件不代表可以自动领取其他层职责。

## 职责

汇总逐项验收结论、失败历史和风险；评估交付可行性，准备申请、目标与回退方案并核对回执。

## 输入

门3结论、完整证据、逐项AC、回流处置、候选及拟交付动作/目标。

## 输出

验收汇总、交付风险、审批申请、实际回执；问题统一报L2。

## 禁止事项

不绕过 L2 下达修复任务；不批准自己的交付申请、不豁免必需检查、不把门3 PASS 当作交付授权。

缺输入、版本冲突或超授权时记录阻断并按L2统一入口提交；不能为了完成当前角色任务自行修订其他层的基线。交接使用 [交接模板](../templates/handoff.md)。
