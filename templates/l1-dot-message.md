# L1与DOT消息模板（按需使用）

这是自然语言说明模板，不是新JSON Schema、工作流状态或批准记录。沿用现有工具字段，不让用户填表；示例占位符不作为真实事实或证据。规则见[合作沟通约束](../docs/guides/l1-dot-communication.md)。

```text
目的/对象：REQUEST / PROPOSAL / DECISION / RESULT / BLOCKED；相关任务/问题及版本
结论/请求：当前结论，或需要接收方执行的具体动作
变化/影响：有变化时注明原/新基线及影响；否则省略
依据/可信范围：事实与证据关键内容；推断/假设/未知及其影响（按实际情况）
待决项：需要决定的缺口、推荐处理和影响；无待决项省略
下一步：责任人、动作、恢复条件；已有明确安排时无需重复确认
```

简单消息只保留前两项及支持它们必需的信息；复杂变更补足后续项。使用增量之前确认接收方能访问同一基线。链接、路径或摘要不能替代接收方无法取得的内容。

标为DECISION的消息必须引用实际审批回执及对象版本；“收到”不是批准。失败、风险、未执行项和累计消耗不能因简短而删去；最终报告仍用[原最终报告模板](final-report.md)。
