# 示例适用范围

原JSON/YAML是正式接入参考，默认L1→DOT流程无需让用户填写这些对象。详见 [进阶说明](../docs/advanced-profile.md)。

## 示例的使用范围

这些文件从最新完整教程提取，保留原有技术示例。它们是**示例或接口草案**，不是本项目已经执行的任务、测试结果或批准记录。

- `REPLACE_*` 必须由真实项目数据替换；不能把示例里的 PASS、ASSIGNED、CAND-001 或时间当作现实状态。
- `contracts/workflow-adapter.yaml` 是项目适配器契约，不能直接当作 govrail 原生配置。
- `contracts/govrail-gates.json` 引用的 adapters 脚本需由实际项目实现，本仓库不提供运行中的产品门禁。
- 原示例格式按其源版本保留；正式接入时还必须落实当前核心规则，如事件绑定 L1-V 包哈希、认证生产者身份及 L2 分诊记录。
- 第3、9、10、11章的工具参数与功能在使用前按项目锁定版本核验；本项目不自动安装或升级工具。

新建任务请优先使用 [模板说明](../templates/README.md)。
